# 🐱 貓咪謎題解題器

Queens / Star Battle 類謎題的離線解題器（PWA）：每個色塊、每橫列、每直行各一隻貓，貓咪彼此不能相鄰（含斜角）。

- **截圖匯入**：自動找出棋盤、格數與顏色
- **下一步提示**：用人類推理技巧說明理由，不只是直接給答案
- **顯示全部貓咪**：直接看完整解答
- **離線使用**：安裝後不需網路，圖片不會上傳到任何地方

## 安裝

- **Android（Chrome）**：開啟網頁 → 「安裝應用程式」。之後截圖 → 分享 → 選「貓咪解題」即可直接解題。
- **iPhone（Safari）**：開啟網頁 → 分享 → 「加入主畫面」。截圖後在 App 內按「選擇截圖」或「貼上截圖」。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 介面與截圖辨識 |
| `queens-engine.js` | 解題與推理提示引擎 |
| `sw.js` | 離線快取、接收分享的圖片 |
| `manifest.webmanifest` | PWA 設定（名稱、圖示、分享選單） |

更新內容後，記得把 `sw.js` 裡的 `VERSION` 加 1，已安裝的使用者才會更新到新版。
